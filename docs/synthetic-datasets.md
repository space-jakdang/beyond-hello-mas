# 합성 데이터와 평가 기록

Obsidian에서도 열 수 있는 Markdown 기록이다. 관련 설계: [[regional-workflow]].

AI는 사례 유형·경계값·결측·도구 실패 조합을 설계하고 생성기를 작성할 수 있다. 실제 자료가 없는 기간/지역을 채우는 용도가 아니라 별도 synthetic 평가셋을 만드는 용도다. 개인정보와 비공개 원천을 공개 합성 파일에 복제하지 않는다.

기록 필드: generator_version, seed, 생성 주체(AI 보조 코드/모델), 입력 출처, 데이터 모드, 생성시각, input/label hash, 개발/시험 지역·기간, 라벨 생성법, 실행 코드/모델/프롬프트 버전. 생성기는 결정적으로 재현하며 입력과 라벨은 분리한다. 잠금 시험은 프롬프트 수정에 사용하지 않는다.

규칙 기반 합성 정답을 같은 규칙으로 맞힌 결과는 계약 검증이다. AI가 만든 평정은 독립 전문가의 타당성 평가를 대체하지 않는다. 외부 지역 일반화·실제 정책 적합성·사회적 효과는 미측정으로 남긴다. 실제/합성 자료와 fake/live 모델 조합을 결과마다 표시한다.

기존 비교: `scenarios/comparison/` 및 `eval/studies/`는 기존 계약으로 보존한다. 새 지역 업무 평가 생성기·보고서는 별도 버전과 디렉터리를 사용하고 변경 시 이 문서에 명령·결과·한계를 추가한다.

## 지역 업무 합성 검증 (W7)

AI가 작성한 생성기 `scripts/generate_workflow_cases.py`로 합성 입력을 구축할 수 있다. 실제 사람이나 관측되지 않은 월을 실제 자료로 생성하지 않는다. 기본 seed는 `20261021`, 버전은 `regional-workflow-cases-1`이다. 36개 사례(12개 계열의 3개월 반복), 강남 개발 7~9월과 춘천 시험 10~12월로 나누며 계열·지역·기간이 겹치지 않는다. 두 지표의 손으로 지정한 규칙 사례와 제공 등급의 보존 검사를 구분한다. 생성기는 분류기를 호출해 정답을 만들지 않지만, 기준 자체가 개발 가정이므로 외부 정답이 아니다.

```sh
uv run python -m scripts.generate_workflow_cases runtime/sample/workflow-cases
make eval-workflow
```

첫 명령은 입력·참조 라벨을 별도 파일로 저장하고 기존 디렉터리를 덮어쓰지 않는다. 두 번째 명령은 동일 생성기를 사용해 입력/라벨 해시, 사용 코드 해시, 분모, 결측, 월별·분할별 결과와 추천 조건 위반을 `eval/reports/<날짜>/<id>/`에 저장한다. `/evaluation`의 **지역 업무 검증** 보고서에서 확인한다. 모델에는 정답이 전달되지 않으며 이 검증에서는 모델 호출 자체가 0회다. 파일을 변조하면 해시 검사에 실패한다.

합성 카탈로그에 미래 수집·만료·타 관할·연령 불일치·미확인 자격의 방해 후보를 넣는다. 위반 0건뿐 아니라 추천 가능한 사례에서 실제로 추천했는지도 검사하므로 모두 보류해서 통과할 수 없다. 분류 오답·예측 누락·실행 예외를 주입하는 테스트가 평가 실패를 확인한다. MAE 분모와 전체 참조등급 일치율 분모는 구분한다.

독립 참조등급, 전문가의 자원 적합성, 실제 제3지역 일반화, 새 워크플로의 A/B/C 효과와 채택 판단은 **미평가(null)**로 둔다. 기존 월별 예측/협업 보고서를 새 업무의 실증으로 재해석하지 않는다. 반복 월은 독립 사례 수를 늘리지 않는다. 실제 평가를 재개할 때에는 [[regional-workflow]]의 최소 사례·두 검토자·사례 단위 불확실성·동일 예산 원칙을 적용한다.

### 구현 검증과 실제 모델 연결 기록

기본 seed에서 36개 계약 사례 중 참조 등급 30개(청년 규칙 18, 제공 등급 보존 12), 결측 보류 6개를 확인한다. 추천 가능 사례 18개는 모두 후보를 받고 필수 조건 위반은 0건이어야 통과한다. 이 수치는 합성 계약의 기대값이며 독립 전문가의 정답률이 아니다. 생성 기준과 통과 조건은 `eval/workflow_contract.json`에 버전으로 보존한다.

2026-10-21 KST, 합성 지역 한 동으로 실제 모델 `gpt-6-luna`의 지역 분석 → 통계 조회/검토 → 매칭 역할 연결을 검사했다. 총 4회 호출이 성공했고 통계/매칭 상태는 reviewed, 조건부 자원은 1건이었다. 기존 장부의 설정 상한을 유지했으며 기록된 비용 추정은 USD 0.001069125였다. 최초 검사 도구의 카탈로그 경로가 없는 파일을 가리켜 중단된 뒤, 합성 fixture 경로를 지정하고 완료된 3회 호출 캐시를 재사용했다. 실제 모델 역할 연결 검사이며 전체 GraphService 재시작·브라우저·승인까지의 live E2E나 독립 품질 평가는 아니다. 전체 사용자 흐름은 sample/fake E2E로 별도 검증한다.

최종 코드 `96447e7`에서 같은 seed로 두 번 실행한 입력/라벨/코드 해시와 평가 결과가 일치했다. [공개 합성 보고서](../eval/reports/20261020/bafb085f-f004-4d9c-b262-3727e0a3a26c/summary.json)에는 입력과 라벨을 함께 보관하되 별도 파일로 분리했다. 브라우저 E2E에서 실제 저장 보고서의 네 평가 축과 미측정 표시를 확인한다.
