## 제출 전 미결 사항과 담당

| 항목 | 담당 | 필요한 근거 | 상태 |
|---|---|---|---|
| 최신 양식·마감·공지 변경 | 사용자/팀 제출 담당 | 공식 공지 URL 또는 접수 계정 문서·확인일 | 미확인 |
| 외부 자료 원본 제출·재배포 | 사용자/팀 자료 담당 | 자료별 이용조건, 주최측의 대체 제출 허용 여부 | 미확인; 자동 문의 발송 없음 |
| 실데이터 지표 manifest·민감도 | 개발 담당 | 원본 hash→변환→지표 검증, 해석 한계 | 후속 구현 |
| 공정한 A/B/C 평가·에이전트 보완 루프 | 개발 담당 | 잠금 사례·동일 도구/한도·전체 실패 기록 | 후속 구현 |
| 독립 내용 평정·운영 과업 평가 | 사용자/팀 검토자 섭외, 독립 검토자 평정 | 전문성·개발 참여 여부·가림 평가 원본 | 미섭외 |
| live 비교 실행 예산 | 사용자/팀 예산 담당 | 기존 누적 한도 내 실행 수 또는 명시적 증액 | 전체 비교 미실행; 예산 초기화 금지 |

공개 Git 패키지와 대회 전용 원본 제출은 서로 다르다. 현재 [제출 재현 절차](release.md)의 tracked-only ZIP은 공개 코드 후보이며 외부 원본 제출 의무 충족을 뜻하지 않는다. 권한 미확인 원본·키·개인 자료·로컬 계획은 넣지 않는다.
