# 정책 분석 통계 자료

`GET /analysis/statistical-sources`는 기존 입력의 지표·집단·기간·원자료 연령별 가용성과 미확보 항목을 반환합니다. 통계 분석의 summary에도 같은 점검이 포함됩니다.

현재 로컬 제공 자료에는 서울 통신 월평균 인구와 춘천 주민 수 문맥이 있습니다. 이것을 정책 수급 대상 인구나 고립 인원으로 바꾸지 않습니다. 연령·기간·모집단이 일치하지 않는 분모로 비율을 계산하지 않습니다. 청년의 양성 합계 자료는 남녀에 중복 합산하지 않습니다.

동일 지표·집단·기간·원자료 연령 안에서 관측 3개 이상이면 비교 분석을 준비할 수 있습니다. 기간 집계는 월별 추이 자료가 아니며 연속 관측 수는 별도 확인합니다. 현재 서비스 실제 이용량·수용량과 검증된 수급 대상 분모는 미확보입니다.

새 공공 통계가 필요하면 제공 기관의 통계표 ID·지역 코드·개편 시점·항목·단위·집단 정의·조회 시각·라이선스를 확인한 후 반입합니다. 정부24 키로 통계 API를 사용할 수 있다고 가정하지 않습니다. 이번 변경은 기존 자료의 가용성 점검이며 외부 통계를 추가 수집한 것으로 표시하지 않습니다.
