## 고정 소프트웨어 기록

[공개 합성 요약](evidence/methodology-20261024.json)은 기능 코드 `85b14db335849f4f846e40beb1832ec7e3c9df9d`의 개발용 두 사례·세 방법 실행이다. 입력 해시·목록에 한정된 코드/프롬프트 해시·실제 호출 수와 비용 상태를 포함한다. 같은 저장 결과 재사용 검사는 추가 호출0이며 독립 반복 측정으로 세지 않는다. 원천 등급은 공통 계산으로 같을 수 있다. 현재 독립 평정자0명이며 성공률·적합성·MAS 품질 개선은 미평가다.

해당 코드의 Python395 passed/4 skipped, frontend build, 전체 Playwright68개(workers=1), 공개 파일 검사와 diff check를 통과했다. 첫 기본5worker 전체 실행은 시간 초과8건이 있었으며, 한 저장 실행은 승인 대기까지31.9초가 걸렸다. 실패를 보존하고 단일 워커로 전체를 재검증했다. 이를 동시 부하 성능이나 운영 지연 보장으로 해석하지 않는다. 4개 skip은 private MCP 미설정2건과 선택적 evaluation 의존성 미설치2건이다.

세 방법의 실제 실행 연결은 [평가 절차](evaluation-quality.md#현재-지역-판단-실행-연결-regional-quality-1)를 따른다. 과거 [고정 도구 비교](agent-comparison.md)와 [workflow 계약 평가](regional-workflow.md)는 각자의 범위·기준 커밋을 유지한다. RAGAS는 근거 충실성의 보조 평가이며 전문가 적합성이나 현장 효과를 대체하지 않는다.

## 저장된 합성 시연

같은 제출 후보의 [시연 준비 도구](../scripts/prepare_methodology_demo.py)와 [실제 브라우저 시연 검사](../frontend/e2e/methodology-demo.spec.ts)를 제공한다. 시연 원천 파일 해시는 위 공개 합성 요약에 기록한다. 세 경로는 [제출 시연 절차](contest-submission.md#시연-3개와-해석)를 따른다. 결측 주입은 새 sample/fake 스냅샷에만 적용하고 원천 파일·기존 실행·예산 장부를 초기화하지 않는다. 가짜 통신이더라도 보완/최종 재검토/저장된 전후 값은 실제 실행 전이이며, 전문가 판단 성능은 아니다. 저장 기록을 재사용해 발표할 때는 재생이라고 밝힌다.

## 제출 관문

공통 단계 기준·비청년 필요 매핑·독립 평정·실제 비교·외부 전이·현장 효과의 미결 상태를 발표에도 남긴다. 공식 양식/마감과 자료 원본 제출 권한은 팀 제출 담당자의 별도 확인 대상이다. 공개 패키지는 검사한 커밋의 추적 파일만 포함하며 로컬 계획·실제 입력·실행 원문·평정자/가림 키·비용 DB는 넣지 않는다. 검토 승인과 예산 승인·기관 전달·지원 집행은 서로 다르다. main 릴리스와 운영 배포 완료를 이 문서로 선언하지 않는다.
