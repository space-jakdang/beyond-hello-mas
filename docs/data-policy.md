# 자료 반입과 공개 범위

서희 MAS 요청 묶음은 전체 로컬 전용입니다. 원본 폴더를 인자로 지정합니다.

```sh
uv run python -m scripts.import_seohee /path/to/MAS-bundle
```

`data/local/seohee/`에 원래 폴더 구조와 바이트를 복사하고 `import.json`에 상대경로와 SHA256을 기록합니다. 기존 반입본이 다르면 덮어쓰지 않고 실패합니다. 심볼릭 링크를 거절하며 원본 코드를 실행하지 않습니다. 원본이 갱신되면 기존 반입 폴더를 로컬에서 별도 보관한 뒤 다시 반입합니다.

전달 번들의 `MANIFEST.csv`에서 **공개 가능**, **공개 가능 (출처 표기)**만 공개 후보입니다. MAS 묶음의 전체 비공개 규칙이 우선합니다. `rules/source_permissions.json`에는 2026-10-18 전달본의 상대 이름·해시·허용 상태만 담았습니다. 데이터 값과 점수표는 포함하지 않습니다. 출처 표기 조건은 자료를 실제 공개할 때 별도로 충족해야 합니다.

공개 검사는 staged 또는 HEAD의 등록부와 파일 바이트를 읽어 비공개 경로·등록된 원본 경로·다른 이름으로 복사한 동일 바이트를 거절합니다. 내용을 바꾸거나 일부 추출한 자료까지 탐지하지는 못합니다. 로컬 파생 결과·프롬프트·화면 캡처도 로컬에만 보관해야 합니다. 새 전달본은 반입 후 등록부를 갱신해야 합니다.

## 8집단 계약

`SegmentV3`는 남/여 × 청년/중년/장년/노년입니다. `rules/age_crosswalk.json`은 자료별 실제 연령 범위를 보존합니다. 사회통합 청년 분석에는 30대가 포함될 수 있으며, 개인 개념 구간과 같다고 간주하지 않습니다. 강남 S1 청년(20·30대)과 춘천 SK 청년(20대)을 통합하지 않습니다.

각 행에 지수 이름, 위험 방향, 자료별 연령 범위, 원본 기간·파일, 좌표 출처를 둡니다. `ym=null`은 기간 집계이며 월별 관측으로 복제하지 않습니다. 지수 결측도 null로 유지합니다. S1만 낮은 값이 위험 방향입니다.

```sh
uv run python -m scripts.generate_groups
make contracts
```

공개 `data/sample/segments-v3.parquet`는 고정 seed로 만든 47개 합성동 × 8집단 × 6개월(2,256행)입니다. 실제 동 코드·값·통계량을 복사하지 않습니다. 기존 v1 입력과 평가 결과는 보존하며, v3 분석 연결은 후속 구현에서 전환합니다.
