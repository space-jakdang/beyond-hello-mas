# 자료 반입과 공개 범위

서희 MAS 요청 묶음은 전체 로컬 전용입니다. 원본 폴더를 인자로 지정합니다.

```sh
uv run python -m scripts.import_seohee /path/to/MAS-bundle
```

`data/local/seohee/`에 원래 폴더 구조와 바이트를 복사하고 `import.json`에 상대경로와 SHA256을 기록합니다. 기존 반입본이 다르면 덮어쓰지 않고 실패합니다. 심볼릭 링크를 거절하며 원본 코드를 실행하지 않습니다. 원본이 갱신되면 기존 반입 폴더를 로컬에서 별도 보관한 뒤 다시 반입합니다.

전달 번들의 `MANIFEST.csv`에서 **공개 가능**, **공개 가능 (출처 표기)**만 공개 후보입니다. MAS 묶음의 전체 비공개 규칙이 우선합니다. `rules/source_permissions.json`에는 2026-10-18 전달본의 상대 이름·해시·허용 상태만 담았습니다. 데이터 값과 점수표는 포함하지 않습니다. 출처 표기 조건은 자료를 실제 공개할 때 별도로 충족해야 합니다.

공개 검사는 staged 또는 HEAD의 등록부와 파일 바이트를 읽어 비공개 경로·등록된 원본 경로·다른 이름으로 복사한 동일 바이트를 거절합니다. 내용을 바꾸거나 일부 추출한 자료까지 탐지하지는 못합니다. 로컬 파생 결과·프롬프트·화면 캡처도 로컬에만 보관해야 합니다. 새 전달본은 반입 후 등록부를 갱신해야 합니다.

## 8집단 계약

`SegmentV3`는 남/여 × 청년/중년/장년/노년입니다. `rules/age_crosswalk.json`은 자료별 실제 연령 범위를 보존합니다. 사회통합 청년 분석에는 30대가 포함될 수 있으며, 개인 개념 구간과 같다고 간주하지 않습니다. 강남 S1 청년(20·30대)과 춘천 SK 청년(20대)을 통합하지 않습니다.

각 행에 지수 이름, 위험 방향, 자료별 연령 범위, 원본 기간·파일, 좌표 출처를 둡니다. `ym=null`은 기간 집계이며 월별 관측으로 복제하지 않습니다. 지수 결측도 null로 유지합니다. S1만 낮은 값이 위험 방향입니다.

```sh
uv run python -m scripts.generate_groups
make contracts
```

공개 `data/sample/segments-v3.parquet`는 고정 seed로 만든 47개 합성동 × 8집단 × 6개월(2,256행)입니다. 실제 동 코드·값·통계량을 복사하지 않습니다. 기존 v1 입력과 평가 결과는 보존하며, 기존 화면은 전환 기간 동안 유지합니다.

## 지역 단계 v2

```sh
DATA_MODE=local LLM_MODE=fake uv run python -m scripts.export_groups
DATA_MODE=local LLM_MODE=fake make classify
# 보존된 임시 3지표 분석
uv run python -m scripts.classify --legacy
```

지역 지수 반입은 기존 `data/local/segments.parquet`의 통계청 동 식별자와 좌표를 사용합니다. `scripts/export_segments.py`로 준비한 47개 동이 필요합니다. 원본 23개 파일의 해시를 확인하고 376개 기본 집단과 강남 비교 지수 132행을 `segments-v3.parquet`에 저장합니다. CSV 원문에 없는 월은 만들지 않습니다. `/analysis/groups`가 v3 분석 API이고 `/analysis`는 기존 화면용 v1 API입니다.

강남 청년 S1은 낮을수록, 춘천 청년 v3는 높을수록 우선입니다. 청년은 원문 최종 판정표에 따라 수준만 높으면 3단계까지이며 카드 신호 결합은 후속 단계에서 적용합니다. 명시한 우선 집단 조건이 있을 때만 +1 규칙을 적용합니다. 중장년·노년은 제공된 G 단계와 강남 구내 순위 단계(1–2위 5, 3–4위 4, 5–9위 3, 10–13위 2)를 보존합니다. 구내 순위와 서울 G v2는 서로 다른 원본 지수일 수 있어 파일명을 함께 제공합니다.

춘천 G는 집단별로 각 갈래를 표준화한 뒤 구조 0.7 + SK 0.3을 합하고 다시 표준화한 원문 값입니다. 원본 코드의 표본 표준편차와 CSV 반올림 오차를 고려해 조합을 검증합니다. 2017년 수급률, 소인구, 두 갈래 일치, 학원가, 결측, 지역 간 비교 불가를 표시합니다. S1과 춘천 청년 v3는 성별로 분리된 지수가 아닙니다. 춘천 청년 인구도 남녀 합계만 별도 성분에 보존하며 성별 인구로 추정하지 않습니다. 지역 단계는 **먼저 찾아갈 순서**이며 개인 고립 진단이나 추정 인원수가 아닙니다.

구 일원2동은 기존 통계청 코드 변환(11230740 → 11230511)을 따라 개포3동에 연결하며 `source_dong_nm`에 원본 명칭을 보존합니다.

## 주간 카드 신호

`/analysis/groups?week=2025-09-08&card_age=20s`처럼 관측 주와 카드 연령(20s/30s)을 선택합니다. 응답의 `weekly`에는 8집단 × 23주의 원본 값·직전 8관측주 기준선·표시 비율·경보와 검증 결과를 제공합니다. 중장년·노년의 카드 신호는 만들지 않습니다.

처음 8주는 기준선이 없으며 `baseline_available=false`입니다. 결측을 정상 위험으로 해석하지 않습니다. 공휴일을 제외한 자료이므로 연속 주는 연속 **관측주**를 뜻합니다. 약한 신호는 2관측주 연속 0.95 미만, 강한 신호는 2관측주 연속 0.90 미만 또는 4관측주 연속 0.95 미만입니다. 춘천 20대 여성의 약한 신호 기준은 0.90입니다.

제공된 비율은 반올림되어 있으므로 규칙 검증은 제공된 값÷기준선으로 수행합니다. 제공된 비율·경보를 바꾸지 않으며 다른 경보가 나오면 적재를 거절합니다. 기준선도 직전 8개 값의 중앙값과 반올림 오차 범위에서 일치해야 합니다. 실제 전달본은 368개 경보 모두 일치했습니다.

청년 지역 단계에는 선택한 시군구·성·카드 연령의 신호를 붙이고, 20대 남성 선택 시 명시된 우선 집단 +1을 적용했다고 표시합니다. 미혼·휴직·부모 동거는 집계에서 추정하지 않습니다. 동별 카드 관측값이 아니며 원천별 연령 범위도 다릅니다. 월별 합성 지수에는 같은 월의 신호만 붙입니다. 실제 기간 집계 지수와 과거 주의 결합은 탐색용 재생이며 당시 예측 성능을 입증하는 백테스트가 아닙니다.

합성 주간 자료 재생성: `uv run python -m backend.tools.weekly_signals`. 원천 카드 거래를 재계산하거나 데이터1을 사용하지 않습니다.
