# 지역 정보 입력 계약

지역 프로필은 고립 지수와 별도로 읽는 인구·가구·주거 집계 문맥이다. 개인 자격·고립 인원·서비스 수요 분모가 아니다.

현재 구현은 입력 검증·지역 코드 대조·관측 식별자·비교 조건과 KOSIS 조회 서비스·프로필 API·준비 상태 진단이다. 미리 첨부한 지역 문맥은 지역 분석가와 통계 분석가의 입력 및 프로필·비교 도구에서 읽는다. 실행 시작 시 프로필을 수집·고정하는 Supervisor 연결과 정책 설계·화면 연결은 후속 단계다. 합성 응답 검사는 실제 제공자 수집 성공이나 정책 품질을 증명하지 않는다.

사용자가 이미 발급한 인증키가 KOSIS임을 확인하여 최초 제공자를 KOSIS 하나로 선택했다. 서버 환경변수는 KOSIS_API_KEY이며 별도 secret은 필요 없다. 정부24 인증과는 별도다.

| 항목 | 우선 원천 | 검증 상태 |
|---|---|---|
| 인구·가구·주택 | KOSIS 인구총조사 표(101/DT_1IN1502) | 공식 표/인자 정의 확인, 실제 인증 응답·원래 8자리 코드·연주기 A·T100/T200/T310 항목명 확인 |
| 일반가구·1인가구·고령/청년 구성 | 101/DT_1JC1502, DT_1IN1503 | 공식 분류/항목 확인. 1인가구 비중은 일반가구 분모. 청년은 19세+20–24+25–29+30–34의 정확 합만 사용. 실제 인증 수치 대조 진행 중 |
| 기존 사업·신청 경로 | 기존 정부24/지역 카탈로그 | 등록 정보이며 시설 수·정원·이용량이 아님 |

자료별 값·단위·모집단·연령·성별·지역 수준·제공자 코드/버전·기준연도·조회/발표시각·원문/해시·누락 사유를 보존한다. 억제/누락 값은 0으로 바꾸지 않는다. 비교는 같은 지표·정의·기간·모집단·지역 수준/버전 안에서만 허용한다. 시군구 값을 동의 관측으로 복제하지 않는다. 현재 조회한 자료의 과거 당시 가용성은 발표시점이 확인되지 않으면 미검증이다.

현재 경계는 2025-07-01의 8자리 통계동 코드다. 신사동 11230510과 개포3동 11230511을 자르면 충돌한다. 따라서 제공자 지역 목록을 정규화하고 부모 관할·동 이름이 유일하게 일치할 때만 원래 제공자 코드를 보존한다. 서로 다른 코드 체계는 별도 검증된 연결 없이는 미확보로 둔다. parent_and_name_only는 경계의 공간적·시계열적 동일성을 확인했다는 의미가 아니다. 분동·코드/이름 충돌은 실패시킨다.

[통계자료 공식 안내](https://kosis.kr/openapi/devGuide/devGuide_0201List.do), [통합검색 안내](https://kosis.kr/openapi/devGuide/devGuide_0701List.do). 고정 HTTPS API만 호출하고 키는 원문 URL·로그·모델 입력·프런트에 포함하지 않는다. 실제 키가 없는 검증은 생성 fixture/실패 경로 검증이며 실제 통계 수집 성공이 아니다.

## 서버 설정과 조회

서버 환경변수 `KOSIS_API_KEY`에 발급된 사용자인증키 하나를 등록한다. `REGIONAL_REFERENCE_YEAR`의 기본값 2020은 문서에서 동 단위 제공을 확인한 기준연도이며 최신 자료라는 의미가 아니다. 실제 키를 연결한 뒤 해당 표의 수록 기간과 제공 항목을 대조하여 운영 기준연도를 선택한다.

`GET /analysis/regional-context?sgg=11230&dong_cd=11230510&reference_year=2020&as_of=2026-10-24`는 자료·출처·기준시점·미확보 항목을 반환한다. `sample`에서만 명시적 생성 fixture를 사용하고, `local`의 키 부재/조회 실패/지역 불일치는 `unavailable`로 남긴다. 누락 원인은 비밀값/원래 요청 URL을 포함하지 않는 코드다. 미완료 자료도 조회 API에서는 상태를 읽을 수 있으며 정상 자료인 것으로 표시하지 않는다.

캐시는 서버 실행 저장 경로의 SQLite에 저장하며 지역·연도·경계와 쿼리 버전별로 분리하고 최대 하루 재사용한다. 저장 응답의 해시를 확인하며 변조된 캐시는 사용하지 않는다. 인구·가구 정의가 다른 원천을 같은 값으로 합치지 않는다. 새 실행에 첨부한 스냅샷을 재개 때 재조회로 바꾸지 않는 것은 Supervisor 연결 단계에서 보장한다. Vercel `/tmp`의 캐시는 영속 저장이 아니며 소실 시 다시 조회한다.

해시 검사는 우발적인 손상을 탐지하며 서버 파일을 임의로 수정할 수 있는 공격자에 대한 인증 수단은 아니다. 캐시 키·표·기간도 재검증하고 잘못된 캐시는 폐기하여 다음 조회에서 복구한다. 프로필 조회 결과의 요청·시각·상태·출처 해시 이력은 최근 500건까지 서버에 보존하며 인증키와 원래 요청 URL은 저장하지 않는다. 일부 표가 실패해도 검증된 다른 표의 관측은 유지한다.

각 표의 원래 8자리 코드와 이름은 요청 관할의 경계 목록과 대조하고, 요청하지 않은 분류는 관측으로 사용하지 않는다. 손상된 선택 정책 캐시는 통계 관측의 조회 실패로 전파하지 않는다. 조회 이력을 읽을 수 없으면 준비 상태를 미확인으로 유지한다.

`/readiness.regional_context`는 키 설정 여부와 자료 조회 상태를 구별한다. `not_checked`는 실제 자료 준비 완료가 아니다. 기존 `ready`는 기존 지역 분석/자원 목록 준비의 의미를 유지한다.

설정된 기준연도의 최근 하루 내 조회가 있으면 마지막 요청 지역의 `ready`/`partial`/`unavailable`과 요청·시점을 함께 표시한다. 이는 모든 동의 준비 상태를 뜻하지 않는다. 프로필의 `resources`는 관할에 맞는 기존 카탈로그 최대 10건과 저장된 정부24 사업 최대 5건을 출처와 함께 연결하며 전체 건수·목록의 수집 상태를 구별한다. 이 조회는 정부24 목록을 새로 수집하지 않는다.

지역 통계는 `total_households`(가구_계)와 `general_households`(일반가구_계)를 구별한다. 1인가구의 분모는 일반가구이며 외국인가구·집단가구를 섞지 않는다. 고령·청년 인구는 성별 합계를 한 번만 사용한다. 연령표 합계와 총인구표의 동일 동·연도 값이 일치할 때만 같은 인구 모집단으로 비율 계산을 허용한다. 모든 측정값에 표/항목/분류 코드를 보존한다. 인구밀도·평균연령은 아직 미확보이며 이 때문에 프로필 상태는 partial일 수 있다. 일부 유효 수치를 활용하되 missing은 0이나 준비 완료로 표시하지 않는다.

## 통계 검토

인구·가구·주거 집계는 고립 지수와 별도로 해석한다. 1인가구 비중의 분모는 같은 정의의 일반가구, 고령·청년 비중의 분모는 같은 정의의 총인구다. 원천·기간·모집단·성별·지역 수준이 다르거나 분모가 0이면 계산하지 않는다. 통계 분석가의 메모는 관측 fact ID, 정책 검토 의미, 확인할 가설, 부족한 증거를 구별한다. 모델에 제공하지 않은 사실은 인용할 수 없고, 조회한 비교 지역의 근거는 실제 도구 관측에서 제공된 경우에만 인용한다. 비교는 집계 규모의 기술 통계이며 위험 순위·원인·서비스 수요가 아니다.

간소화한 모델 입력에도 제공자 지역 코드·경계 버전·표·항목·분류·게시 시점과 미확보 사유를 남긴다. 게시 시점이 없으면 과거 당시 가용성을 확인한 것으로 해석하지 않는다. 계산·스키마·조회/재검토 제어의 생성 fixture 검사와 실제 모델 해석 품질 평가는 구별한다.

과거 첨부 프로필에 일반가구 지표 자체가 없을 때만 같은 정의의 `total_households`를 호환 분모로 사용한다. 일반가구 지표가 존재하지만 missing인 경우에는 대체하지 않는다. 현재 KOSIS 프로필은 일반가구를 별도로 제공하므로 이 호환 경로로 서로 다른 가구 모집단을 합치지 않는다.

동별 비교는 관측 지역 코드가 서로 다른 동 자료만 사용한다. 구 단위 문맥은 원래 지역 수준과 함께 보존하되 동별 비교에서는 제외한다. 같은 구 통계를 여러 동에 첨부해도 독립된 동 관측으로 세지 않는다.
