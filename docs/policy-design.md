# 통계 기반 정책 설계

기존 정책 추천은 실제 조회된 지원 정보이고, 정책 설계는 담당자가 검토할 새 제안입니다. 타지역의 정책 사례를 찾았다고 해당 정책을 현재 지역 주민이 이용할 수 있다고 판단하지 않습니다.

통계 분석은 같은 척도·집단·기간 안에서 분포·변화·민감도와 자료 결측을 정리하고, 관측된 요인에 대응하는 필요를 정책 탐색으로 전달합니다. 집계 상관이나 높은 단계가 개인의 원인·자격·수요 인원을 입증하지는 않습니다. 인구 분모나 예산 자료가 없으면 해당 수치를 생성하지 않습니다.

정책 설계의 입력은 지역 관측 ID, 통계 결과, 카탈로그 부족, 지정 범위의 정책 조회 결과, 상세 조회로 확인한 유사 정책입니다. 검색 미완료는 `search_incomplete`, 확인된 후보가 있는 경우 `candidate_found`, 지정한 출처·범위를 조회했지만 확인된 후보가 없으면 `no_verified_candidates`입니다. 마지막 상태도 현실의 모든 정책이 없음을 뜻하지 않습니다.

정책 초안은 대상 집단·서비스 제안·유사 사례와 다른 지역 여건·적응 방안·운영 단계·필요 역할·실현 가능성 확인 목록·형평성 위험·효과 검증 계획·담당자 질문을 제공합니다. 기존 정책의 사실은 실제 상세 응답 필드와 정확히 일치하는 인용으로 검증하고, 적응 방안은 인용한 정책 ID와 연결합니다. 문장 유창함은 실행 가능성의 증거가 아닙니다.

모델은 `draft`, `needs_evidence`, `needs_human`만 반환할 수 있습니다. 정상 초안은 확인된 범위의 공백과 인용된 유사 사례의 적응 방안을 요구합니다. 예산·정원·법적 근거는 확인 완료로 생성할 수 없습니다. 사람의 정책 검토 승인도 예산 편성·기관 약정·현장 시행 승인이 아닙니다. 초안은 기존 자원 배정과 별개로 보존합니다.

현재 이 문서는 정책 설계 계약입니다. 도구·Supervisor 실행·검토 화면·독립 평가 연결은 후속 구현에서 제공하며 실제 정책 효과는 별도 검증이 필요합니다.
