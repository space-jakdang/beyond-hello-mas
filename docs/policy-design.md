# 통계 기반 정책 설계

기존 정책 추천은 실제 조회된 지원 정보이고, 정책 설계는 담당자가 검토할 새 제안입니다. 타지역의 정책 사례를 찾았다고 해당 정책을 현재 지역 주민이 이용할 수 있다고 판단하지 않습니다.

통계 분석은 같은 척도·집단·기간 안에서 분포·변화·민감도와 자료 결측을 정리하고, 관측된 요인에 대응하는 필요를 정책 탐색으로 전달합니다. 집계 상관이나 높은 단계가 개인의 원인·자격·수요 인원을 입증하지는 않습니다. 인구 분모나 예산 자료가 없으면 해당 수치를 생성하지 않습니다.

정책 설계의 입력은 지역 관측 ID, 통계 결과, 카탈로그 부족, 지정 범위의 정책 조회 결과, 상세 조회로 확인한 유사 정책입니다. 검색 미완료는 `search_incomplete`, 확인된 후보가 있는 경우 `candidate_found`, 지정한 출처·범위를 조회했지만 확인된 후보가 없으면 `no_verified_candidates`입니다. 마지막 상태도 현실의 모든 정책이 없음을 뜻하지 않습니다.

정책 초안은 대상 집단·서비스 제안·유사 사례와 다른 지역 여건·적응 방안·운영 단계·필요 역할·실현 가능성 확인 목록·형평성 위험·효과 검증 계획·담당자 질문을 제공합니다. 기존 정책의 사실은 실제 상세 응답 필드와 정확히 일치하는 인용으로 검증하고, 적응 방안은 인용한 정책 ID와 연결합니다. 문장 유창함은 실행 가능성의 증거가 아닙니다.

모델은 `draft`, `needs_evidence`, `needs_human`만 반환할 수 있습니다. 정상 초안은 확인된 범위의 공백과 인용된 유사 사례의 적응 방안을 요구합니다. 예산·정원·법적 근거는 확인 완료로 생성할 수 없습니다. 사람의 정책 검토 승인도 예산 편성·기관 약정·현장 시행 승인이 아닙니다. 초안은 기존 자원 배정과 별개로 보존합니다.

현재 이 문서는 정책 설계 계약입니다. 도구·Supervisor 실행·검토 화면·독립 평가 연결은 후속 구현에서 제공하며 실제 정책 효과는 별도 검증이 필요합니다.

## 다른 관할 정책의 참고 사례 조사

`policy_analogues(local_scope, query, target_group)` MCP 도구는 현지 관할을 제외한 지원 관할에서 검색어가 일치하는 최대 5개 사례를 조회한다. 실시간 상세·출처 URL·조회시각이 있는 정책만 참고 근거로 반환한다. 검색 총건수·다음 페이지·부분 실패·오래된 목록을 함께 보존한다. 대상집단 적합성과 인구·예산·기관의 유사성은 아직 확인되지 않았음을 표시하며 에이전트가 원문을 대조해 적용 차이를 설명해야 한다.

이는 현지 신청 가능 정책 추천이 아니다. 지원 범위는 중앙·서울·강남·강원·춘천이며, 검색어 일치를 통계적 지역 유사성으로 부르지 않는다. 유효한 사례가 없거나 목록이 오래되면 `needs_evidence`로 끝난다.

## Supervisor가 위임하는 정책 설계

지역 업무에서 정책 조사 후보가 없으면 Supervisor가 별도 정책 설계 노드에 결과를 전달한다. 검색이 불완전하거나 카탈로그 필터를 수행하지 않았다면 모델·추가 조회 없이 `needs_evidence`로 보류한다. 확인된 검색 범위의 공백일 때만 설계 에이전트가 검색어를 선택해 `policy_analogues`를 호출하고, 실제 원문을 받은 후 담당자용 구조화 보고서를 작성한다. 에이전트 결정은 최대 2회, 사례 조회는 1회이며 기존 실행의 모델 호출·비용·입력 한도를 공유한다.

보고서에는 관측 근거 ID, 대상, 제공 방식, 참고 정책과 현지 차이, 운영 단계, 필요한 역할, 미확인 비용·정원·법률, 형평성 쟁점, 기준선·비교 방법·성공/중단 기준 합의 계획을 담는다. 처음 5개 공백 집단을 전달하고 나머지 집단 수를 명시하며, 전체 지역을 포괄하는 수요 추정이 아니다. 인용 원문·ID·출처는 서버에서 대조한다. 조회 또는 검증 실패는 근거 보류로 저장된다.

도구 관측과 최종 보고서를 SQLite에 저장해 그래프 재시작 시 재사용한다. 저장 전 외부 조회 도중 종료하면 조회가 다시 실행될 수 있지만, 저장된 관측은 중복 조회하지 않는다. 관찰 화면에서 정책 설계 역할과 도구/근거 전달을 확인할 수 있다. 일반 자원 제안 승인은 정책안의 별도 검토 승인이나 예산·시행을 의미하지 않는다.
