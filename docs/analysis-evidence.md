# 지역 분석 근거와 민감도

`uv run python -m eval.analysis_evidence`는 공개 합성 자료, `uv run python -m eval.analysis_evidence --local`은 이미 반입한 로컬 집계를 읽는다. API·LLM 호출과 원본 수정은 없다. 결과는 각각 `runtime/sample/analysis-evidence/UUID/summary.json`, `runtime/local/analysis-evidence/UUID/summary.json`에 보관한다. 로컬 결과는 공개하지 않는다.

## 원천과 결합 단위

보고서 `lineage`는 지표별 전달 파일 hash, 기간, 실제 연령 구간, 성별, 동 단위, 기본/비교 지수, 월 유무와 결측 수를 기록한다. 로컬은 전체 반입 등록부 hash를 재검사한다. 전달 집계의 식별·변환 검증이며 공급자 원자료에서 독립 재계산했다는 뜻은 아니다.

| 채택 지표 | 전달 파일 | 변환·판단 | 해석 경계 |
|---|---|---|---|
| 강남 청년 S1 | gangnam_S1.csv | [변환](../scripts/export_groups.py), [구간·단계](../backend/tools/region_stage.py) | 낮을수록 우선 검토. 20·30대 지수는 성별 공통, 성별 인구와 구분 |
| 춘천 청년 v3 | chuncheon_youth_risk_v3.csv | 같은 변환·구간 코드 | 높을수록 우선 검토. 20–34세, 성별 공통. 복지율 2017년 한계 |
| 강남 비청년 구내 순위 | gangnam_within_rank.csv | 22동 순위 구간→단계 | 서울 전체 비교 지수와 별도. 타 지역과 순위 비교 금지 |

| 청년 카드 T1b·R1 | card_weekly_signals.csv | [직전 8관측주 중앙값·경보 감사](../backend/tools/weekly_signals.py) | 시군구×성×20대/30대×주. 동별 관측이 아님; 중장년·노년에 적용하지 않음 |

[연령 대응표](../rules/age_crosswalk.json)를 사용하며 개념상 연령과 관측 자료 연령이 같다고 가정하지 않는다. 지역 기간 집계에는 월이 없으며 월별 관측으로 복제하지 않는다. 코드 hash는 보고서에 포함한다. 실제 입력·변환과 독립적인 검증은 아직 별도 과제다.

## 수행하는 검증

- 주간 경보: 6/8/10개 직전 관측의 중앙값, 직전 8개 평균을 비교한다. 현재 관측은 기준선에서 제외한다. 원래 8주 기준선이 있더라도 대안 이력이 부족한 경우 비교에서 제외하고 제외 수를 남긴다. 경보 차이는 오경보율이 아니다.
- 춘천 G: 구조 가중치 .6/.7/.8을 집단 내부에서 비교해 순서 역전 쌍/전체 쌍과 최대 순위 이동을 기록한다. 동 코드를 동률 해소에 사용한다. 원본 단계는 수정하지 않으며 구성요소가 없거나 상수면 미평가 사유를 남긴다.
- 청년 구간: 지표값 ±.01 절대 변화의 단계 변화를 기록한다. 지표 척도가 달라 두 지역의 변화율을 비교하지 않는다. 주간 신호·우선순위 가산은 포함하지 않은 기본 단계 민감도다.
- 결측: 값을 모두 결측으로 둔 경우 미판정 수/전체 수를 검사한다. 실제 결측 발생률을 추정한 실험이 아니다.

민감도 결과를 보고 가중치나 임계값을 최적화하지 않는다. 계절성·상권·학사 일정은 미검증 대안 가설이다. 고립 정답이 없으므로 `actual_isolation_accuracy`는 null이다. 외부 개인 설문 모델 AUC와 지역 에이전트 품질을 합산하지 않으며 외부 모델을 이 실행에서 평가하지 않는다. [합성 월별 예측](evaluation.md)은 별도 실험이다.
