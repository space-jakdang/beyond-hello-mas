# 에이전트 업무 UI

참고: [awesome-design-md Stripe 분석](https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/stripe), [TDS](https://developers-apps-in-toss.toss.im/design/components), [ListRow](https://tossmini-docs.toss.im/tds-mobile/components/ListRow/list-row-overview/), [Badge](https://tossmini-docs.toss.im/tds-mobile/components/badge/).

카탈로그의 밝은 canvas, 짙은 잉크, 얇은 구분선, 숫자 가독성과 TDS의 제목/보조 설명/상태/행동 위계를 참고한다. 제품의 녹색 강조색은 유지하고 중립 배경·넉넉한 여백·목록 중심 작업 화면을 사용한다. 전용 폰트/로고/이미지·TDS 코드/패키지를 복사하지 않는다. 현재 앱은 앱인토스가 아니므로 제한된 자료를 그대로 배포하지 않는다.

지역 업무가 기본 진입점이다. Supervisor·지역 분석·통계 분석·자원 매칭·공무원 검토를 실제 이벤트 상태로 표현한다. 미실행/실행중/완료/보류/실패를 구분한다. 작업 순번과 위험 1~5등급은 별도 텍스트·색으로 구분한다. 결과에는 데이터 모드/방법론/기간/근거 버전이 항상 따라간다.

공통 토큰: ink #191f28, muted #53616d, canvas #f4f6f8, surface #fff, accent #087f72, line #e5e8eb. 8px 간격계, 12~20px 모서리, 16px 본문, 44px 최소 터치 영역. 수치는 tabular-nums. 카드 중첩보다 섹션 제목과 행 구분을 우선한다.

본문 건너뛰기·키보드 포커스·폼 라벨·모바일 재배치 유지. 탭은 버튼과 aria-selected/tabpanel 연결 및 키보드 탐색을 지원한다. 상태는 색만으로 전달하지 않는다. JSON은 개발자용 details로 접고 근거·결론·다음 행동을 먼저 제공한다. PNG는 보조이며 데이터 선택·차트·상세 연동이 본 기능이다.

상태는 항상 한글 라벨과 사유를 제공하고 실행중은 진행 표시, 보류는 확인 필요, 실패는 오류 유형을 함께 표시한다. 상태 변경은 aria-live=polite로 알린다. 탭은 활성 항목만 tabindex=0, 좌우/Home/End 키 이동, aria-controls/aria-labelledby로 연결한다. 실제 검토 상태(반려/보완)는 작업 완료 배지와 별도로 표시한다.

구현 진입점은 `/workspace`다. 기존 `/neighborhoods`는 원자료·주간 탐색으로 유지한다. 업무 결과 지도는 기존 `MapView`를 재사용하되 등급은 선택 실행의 스냅샷을 사용한다. 동 선택으로 분석 표와 자원 제안을 함께 좁히고, 통계는 업무 전체 모집단 기준임을 유지한다. 업무 입력 변경과 이미 생성된 제안은 분리한다. `/console?run=…`에서 같은 제안의 탭을 확인하고 승인·반려·보완 요청을 수행한다. 원자료·지도 배경의 최신 조회가 이전 제안 수치를 다시 계산하지 않는다.


실제 지역 탐색과 업무 지시를 연결한다. 인덱스 구조도는 역할·도구·산출물과 재검토 경로를 설명하고 실행 상태처럼 표현하지 않는다. 각 페이지의 업무 경로 안내와 업무별 실제 전달 기록은 별도로 표시한다. 동네 분석에서 선택한 관할·동·성별·집단을 지역 업무로 전달하며 관측 월은 제공 자료에서 선택한다. 월이 없는 기간 집계의 실행 기준 월은 관측 월로 표시하지 않는다. 원자료 조회 실패 시 업무 지시를 막으며 합성 자료로 대체하지 않는다.

지도는 local 자료에서는 실제 행정동 경계·동명, sample에서는 명시적인 합성 격자다. 원자료 지도는 주간 신호 보정 탐색, 업무 지도는 실행 당시 기본 지수 등급이므로 양자의 차이를 안내한다. 통계·매칭 결과가 준비되면 같은 동의 제안으로 연결한다. 등록 자원 부족 시 정책 조사 경로를 요청하며, 도구·예산·근거 부족은 보류 상태와 기록으로 남긴다.

동네 분석은 선택 주의 T1b/R1 값·8관측주 기준선·비율·신호를 요약 카드로 먼저 보여준다. 원천 JSON과 파일/규칙은 접어서 제공한다. 주간 신호는 시군구 집단 단위이며 개별 동의 실측값으로 표시하지 않는다.

관찰 화면 첫 진입은 지역 선택→추가 조회/보완→제안 검토 안내를 제공한다. 화면 진입 자체는 실행을 생성하지 않으며 개발 시나리오와 실제 지역 업무 진입을 구분한다.

담당자 콘솔은 최근200건 내 전체·위기/인계·사람 미확인·승인 요청 알림 수와 필터를 제공한다. 요청 알림을 현재 승인 대기 건수로 오인하지 않도록 과거 요청 포함을 명시한다. 필터는 사람 확인이나 승인 상태를 변경하지 않으며 자동 브라우저 수신과 사람 확인은 별개다.

평가 화면은 보고서 분모·미완료·재현성 요약을 먼저 제공하고 지역 업무 계약/합성 미래 예측의 핵심값을 카드로 표시한다. 새로운 점수는 계산하지 않고 저장된 보고서 값을 사용한다. 독립 사례 수와 반복 분모, 합성 결과와 실제 미측정 품질을 구분하며 세부 표는 모바일 가로스크롤로 제공한다.
