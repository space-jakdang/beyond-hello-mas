# 정책 대안 평가와 보고서 검증

평가 화면의 **정책 대안 품질**에서 저장 실행을 선택합니다. 동별 세 개 생성 수, 구상안·테스트 작성 수, 실제 근거 평가 가능 수를 분리합니다. 세 개 충족률과 전략 이름 차이를 정책 품질 점수로 사용하지 않습니다. 원문 인용 대조도 정책 효과나 자격 충족의 증거가 아닙니다.

기존 분류·추천 평가는 그대로 사용합니다. 지역 단계는 독립 참조 등급·혼동행렬·단계 오차·고위험 누락을 보고, 자원과 정책 후보는 P@3/Recall@3/NDCG@3와 조건 위반을 확인합니다. 관련 후보가 한 개일 때 무관한 후보로 채우지 않습니다. 독립 정답과 미사용 실제 지역·기간이 없으면 일반화 성능은 N/A입니다.

## 독립 정책안 평정
화면의 현재 `input_hash`를 복사하고 아래 형태의 JSON을 등록합니다. 입력 해시는 세 대안·원천·검토 revision 전체에 연결됩니다. 수정 전 평정이 수정 후 문서에 승계되지 않습니다. 개발 참여자는 독립 점수에서 제외하며, 축마다 독립 검토자 2명 미만이면 N/A, 2점 이상 차이면 불일치로 표시합니다. 독립성은 제출한 검토자 정보에 따른 것이며 실제 신원 검증을 대신하지 않습니다. 같은 버전의 기존 평정을 덮어쓰지 않으며 새 검토자 평정은 추가할 수 있습니다.

```json
{
  "input_hash": "화면의 현재 입력 해시",
  "reviewers": [{"id":"reviewer-1","expertise":"지역복지","development_participant":false}],
  "ratings": [{
    "alternative_id":"화면의 대안 ID",
    "reviewer":"reviewer-1",
    "scores":{"grounding":null,"feasibility":null,"clarity":null,"equity":null,"evaluation_plan":null,"distinctness":null},
    "reason":"평정 근거와 불확실성"
  }]
}
```

각 축은 1(중대한 보완 필요)~5(근거가 분명하고 해당 기준 충족) 또는 null(판단 불가)입니다. 근거 연결, 실행 가능성, 담당자 이해도, 형평성, 평가 계획, 대안 간 실질적 차이를 따로 검토합니다. 운영자의 승인 버튼과 전문가 독립 평정은 별개입니다.

## RAGAS

```sh
uv run --extra evaluation python -m eval.alternative_grounding OWNER_UUID \
  --store runtime/local/events.sqlite3 --env .env --data-mode local \
  --other-ledger runtime/sample/events.sqlite3
```

기존 실제 호출 장부를 지정합니다. 생성 당시 모델 입력과 일치하는 기록을 찾아 **제안 근거 설명**만 Faithfulness로 평가합니다. 신규 운영 계획을 이미 실현된 사실처럼 평가하지 않습니다. 구상안·테스트 작성·지역 근거가 없는 안은 제외하고 N/A로 남깁니다. 결과는 평가 화면에 연결되며 비용은 기존 누적 장부에 기록됩니다. 같은 입력의 반복 실행은 저장 결과만 반환합니다. 중단된 pending 평가도 자동 유료 재시도하지 않습니다. 사람 judge 일치도와 정책 효과는 별도 미평가입니다.

## 재현 검증 범위

자동 테스트는 0/1/여러 후보, 자료·도구·모델 장애, 부분 대안 실패, 전체 집단 실행, 취소, 중복 요청, 검토 버전 충돌, 모바일, 한글 PDF/DOCX, 출력 시 추가 모델 호출 없음 등을 확인합니다. 이 테스트 성공률은 정책 적합성이나 실제 위험 분류 정확도가 아닙니다. 실제 API 검증과 독립 평가의 기록은 개발 검증 결과에 각각 표시합니다.

부모 업무의 `fallback_count`는 구상안이 하나라도 포함된 **동 묶음 수**입니다. 평가 화면의 `template_count`는 개별 구상안 수이며 분모가 다릅니다. 이 기능은 기존 로컬 신뢰 환경을 따릅니다. 공개 다중 사용자 배포에는 별도의 인증·접근제어와 평정자 신원 확인이 필요합니다.

## 2026-10-23 실제 연결 확인

강남구·춘천시 각 한 동에서 실제 로컬 자료와 OpenAI·정부24 흐름을 실행해 모두 승인 대기와 모델 작성 대안 3개를 확인했습니다. 각각 8회·9회 모델 호출, 설정 단가·사용 토큰 기준 약 $0.00418·$0.00500입니다. 강남구의 기존 정책 최종 후보는 0개(공식 참고자료 5개 조회), 춘천시는 1개(live 상세)였으며 관련 없는 후보로 숫자를 채우지 않았습니다.

강남구 한 동의 전체 8개 집단 실행은 38회 호출(약 $0.02009)로 모두 승인 대기에 도달했습니다. 최초 생성은 두 안에서 긴 근거 ID 반환 오류가 있어 구상안으로 대체됐습니다. 이 실패 기록을 보존하고 짧은 참조 번호를 서버에서 원래 ID로 복원하도록 수정한 뒤 명시적 새 버전을 생성했습니다. 새 버전은 세 안 모두 8개 지역 근거에 연결됐지만 공식 정책을 직접 인용하지 않아 `partial`로 남겼습니다. 이를 모든 집단의 현장 적합성 검증으로 해석하지 않습니다.

단일 실행의 세 근거 설명에 RAGAS Faithfulness를 적용한 결과는 0.875 / 0.667 / 0.750입니다. 6회 judge 호출(약 $0.00270)을 기록했습니다. 표본 3개이며 사람 judge 일치도·정책 효과·외부 일반화 점수가 아닙니다. 실제 저장된 전체 집단 새 버전의 PDF 5쪽·Word 다운로드와 추가 모델 호출 0회를 확인했습니다. 실제 연결 검증은 기존 모델·가격 설정과 출력 상한 8,192토큰·요청 제한 120초를 사용했습니다. 비용은 설정 단가 기반 추정이며 공급자 청구서 대조는 수행하지 않았습니다.
