# 동네별 분석 지도

`/neighborhoods`의 동네 분석은 run 실행이나 LLM 호출 없이 현재 서버의 집계 데이터를 읽습니다. 지역(강남/춘천), 분석 월, 연령을 선택하면 지도와 동 목록의 단계가 함께 바뀝니다. 지도는 SVG 경계만 표시하며 외부 지도 타일이나 API 키가 필요하지 않습니다. 클릭 또는 Tab+Enter/Space로 동을 선택하고 확대 후 스크롤로 이동할 수 있습니다.

sample은 기존 합성 데이터의 비지리 격자입니다. 실제 동 이름이나 위치에 합성치를 덧씌우지 않습니다. local은 [2025-07 행정동 경계](../data/geography/README.md)와 통계동 코드·이름이 일치한 항목만 지도에 표시합니다. 미연결 항목은 수와 목록으로 남습니다. 서버의 DATA_MODE가 모드를 결정하며 브라우저 요청으로 바꿀 수 없습니다.

전체 연령은 관측된 연령별 단계의 최댓값이며 평균이 아닙니다. 관측 연령 수가 6보다 작으면 결측이 포함된 요약입니다. 지역/연령 필터는 기존 분류 결과를 선택할 뿐 분위 기준을 다시 계산하지 않습니다. 단계는 임시 기준이며 개인 진단이나 검증된 고립률을 뜻하지 않습니다. 원본 입력이나 경계가 없거나 손상되면 오류를 표시하고 sample로 대체하지 않습니다.

로컬 분석 입력을 준비한 후 `DATA_MODE=local LLM_MODE=fake make dev`로 실제 분석 지도를 볼 수 있습니다. 실제 분석 화면 캡처와 파생 결과는 `runtime/local/`에만 저장하고 제출물에는 넣지 않습니다.
