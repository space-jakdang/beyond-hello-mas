# 공식 출처 기반 자원 카탈로그

`reviewed.json`은 2026-10-18에 공식 정부·지자체 또는 운영기관 공개 안내를 확인해 수기 구조화한 **30개 서비스/이용 지점**이다. 서울마음편의점 6개 지점이 포함되므로 서로 다른 30개 사업을 뜻하지 않는다. 노인맞춤돌봄 지역 운영과 특화지원도 동일 사업군이다. `program`으로 사업군을 구분한다. 합성 자원은 포함하지 않는다.

`curated-20261018-1/resources.csv`는 기존 Resource v2 계약으로 읽는다. `manifest.json`은 입력·출력 hash, 관할·욕구 분포, 같은 출처를 공유하는 항목과 제외 사유를 기록한다. 기본 실행은 기존 합성 카탈로그다. 실제 카탈로그를 선택하려면 `.env`에 `RESOURCE_CATALOG=curated`를 설정한다. 데이터와 LLM 모드는 별도다.

**출처 검토와 이용 자격 확정은 다르다.** 현재 웹 안내의 사실을 Codex가 확인했으며 독립적인 사람 평가·기관 전화 확인은 하지 않았다. 모든 자원은 `confirmed:<resource-id>` 조건이 true인 경우에만 추천된다. 담당자가 해당 사례의 거주지·세부 연령·소득·중복 급여·프로그램 선정·현재 접수 가능 여부를 확인해야 한다. 0~120은 원문에 수치 연령이 없을 때의 필터 미적용 범위이며 전 연령 이용 가능하다는 주장이 아니다. `active=true`는 공개 안내를 수집한 상태이고 영구 운영이나 잔여 정원을 보장하지 않는다. `valid_until=null`은 종료일을 확인하지 못했다는 뜻이다. 강원 상담전화 안내는 갱신일이 오래됐으므로 최신 운영 여부를 재확인해야 한다.

`needs`, `intensity`, 고립 관련성은 프로젝트의 임시 매핑이며 공식 판정이나 효과 검증이 아니다. 전화 상담, 안부 지원, 사회적 교류 자원이 많고 경제·주거·고용 자원은 부족하다. 실제 접근성이나 지원 적합성은 서희의 후속 사람 평가 대상이다. 현 카탈로그만으로 공급이 충분하다고 결론짓지 않는다.

수기 큐레이션은 계획의 허용된 축소 범위다. 자동 LLM 추출, 병렬 수집, 모델 기반 검수는 실행하지 않았으며 비용은 API 호출 0건 기준 $0이다. 원문 전체나 이미지 대신 짧은 사실 요약과 URL을 보존한다. 원문URL과 필드별 해석은 `reviewed.json`에서 추적한다.

```sh
uv run python -m scripts.curate
# 새로운 입력 버전은 새 출력 폴더에 저장한다.
uv run python -m scripts.curate --input data/catalog/reviewed.json --output runtime/sample/catalog-check
```

동일 입력 재실행은 동일 출력이다. 다른 내용을 같은 출력 경로에 덮어쓰지 않는다. 일부 항목이 검증에 실패하면 실패를 manifest에 남기고 해당 항목은 내보내지 않으며 종료 코드 1을 반환한다. source_reviewed는 출처 검토 상태이며 human_reviewed를 대신하지 않는다.
