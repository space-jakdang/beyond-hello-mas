# 보고서 한글 글꼴
NanumGothic-Regular.ttf는 Google Fonts의 [Nanum Gothic](https://github.com/google/fonts/tree/main/ofl/nanumgothic) 원본을 수정 없이 포함합니다. 저작권 NHN Corporation, SIL Open Font License 1.1. 동봉한 OFL.txt에 저작권과 재배포·문서 포함 조건이 있습니다. PDF는 이 글꼴을 포함하며 다운로드 시 외부 글꼴·URL을 요청하지 않습니다. Word는 NanumGothic을 지정하고 설치되지 않은 환경에서는 문서 편집기의 한글 대체 글꼴을 사용합니다.
